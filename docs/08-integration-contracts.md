---

## 1. Core Architectural Invariants

1. **FastAPI is the sole application authority**: Owns identifiers, timestamps, state transitions, authentication, and audit logs.
2. **AI Engine is strictly advisory**: Zero queue, database, assignment, or prescription mutation permissions.
3. **P0 Emergency Escalation**: P0 signals immediately branch to `p0_escalated` emergency handling and do **not** enter the normal Super Admin queue approval flow.
4. **Super Admin Review Gate**: Required for all P1, P2, and P3 intakes before entering the active doctor-facing queue.
5. **Immutable Historical Audit**: AI assessments remain immutable; human overrides record who, when, what, and why.

## 2. Field-by-Field Contract Review & Classification

Each field and contract is classified into:
- **CONFIRMED**: Frozen for MVP development. Both backend and frontend agree on shape and semantics.

### 2.11 Workflow & Status Transitions

```
Standard Patient Flow:
intake_submitted ──► assessment_pending ──► assessment_ready ──► awaiting_review ──► approved ──► queued ──► called ──► in_consultation ──► completed

Emergency P0 Flow:
intake_submitted ──► assessment_ready ──► p0_escalated (Immediate human intervention; bypasses queue)

Failure / Exception Flows:
intake_submitted ──► assessment_pending ──► assessment_failed (AI timeout/error -> manual review)
awaiting_review  ──► needs_clarification (Admin requests patient clarify)
awaiting_review  ──► rejected (Admin rejects intake)
queued           ──► skipped (Patient no-show)
```

| Lifecycle State | State Authority | Triggered By | Classification |
|---|---|---|---|
| `intake_submitted` | FastAPI | Patient survey submit | **CONFIRMED** |
| `assessment_pending` | FastAPI | Dispatched to AI Engine adapter | **CONFIRMED** |
| `assessment_ready` | FastAPI | AI response received & schema validated | **CONFIRMED** |
| `p0_escalated` | FastAPI | P0 signal or critical safety flag detected | **CONFIRMED** |
| `awaiting_review` | FastAPI | P1-P3 assessment ready for Super Admin | **CONFIRMED** |
| `approved` | FastAPI | Super Admin approves or overrides | **CONFIRMED** |
| `rejected` | FastAPI | Super Admin rejects intake | **CONFIRMED** |
| `needs_clarification`| FastAPI | Super Admin returns intake for clarification | **CONFIRMED** |
| `queued` | FastAPI | Queue entry created with turn number | **CONFIRMED** |
| `called` | FastAPI | Doctor initiates patient call | **CONFIRMED** |
| `in_consultation` | FastAPI | Doctor starts consultation | **CONFIRMED** |
| `completed` | FastAPI | Doctor completes consultation notes | **CONFIRMED** |
| `assessment_failed` | FastAPI | AI engine timeout, crash, or malformed schema | **CONFIRMED** |
